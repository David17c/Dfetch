## Command-line flags

`-h, --help` Show available flags

`-m, --list-modules` List all available modules

`-l, --no-logo` Disable ASCII art for this run

`-C, --no-color` Disable color output for this run (some ASCII art may become unrecognizable)

`-L, --set-logo <path / distro name>` Set the logo from a custom ASCII art file or distro name

`-c, --set-config <path>` Use the specified config file

`--reset-config` Regenerate the default config file
