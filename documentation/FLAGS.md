## Command-line flags

`--help` Show available flags

`--list-modules` List all available modules

`--no-logo` Disable ASCII art for this run

`--no-color` Disable color output for this run (some ASCII art may become unrecognizable)

`--set-logo <path / distro name>` Set the logo from a custom ASCII art file or distro name

`--set-config <path>` Use the specified config file

`--reset-config` Regenerate the default config file
